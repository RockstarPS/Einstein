# Metadata Library

Metadata library is used to store retrive partition and software information in the persistent memory

# Stable Releases

## Branch

### master

Branch for latest stable deliveries

### Tags

#### rel-20220922-2.0.0

* Support for ABA partitions
* Support for Physical Memory Partitions

**Note:** Not backward compatible with 1.0.0

#### rel-20221101-1.2.0

* Bug fix to support 64 bit META offset address

#### rel-20221020-1.1.0

* META_A_OFFSET and META_B_OFFSET now must be multiples of 512 bytes.

#### rel-20220530-1.0.0

* Support for EMMC / NOR Memories
* Support for AES/RSA Crypto
* Support for BSDIFF algorithm
* Support for ISO Update Package
* Support for Alliance packaging format ( PDX, FOTA, VIP)
