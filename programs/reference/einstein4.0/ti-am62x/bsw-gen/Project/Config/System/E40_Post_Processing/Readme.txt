Description: 
This post processing tool supplements the A2TOM tool for enhanced functionalities. It enables the design of array
of user defined data types. Please see the below supported data types section for the list of supported user defined data types.
This tool post process the A2TOM generated ARXML file to encompass the respective functionality. It also had some custom processing
functionalities to cover the descripensies between the UML high level design and generated ARXML file. For example, sometimes the 
"Event trigger runnbales" are not generated by the A2TOM in those case this tool can post process the ARXML to incorporate the "Event
trigger runnbales". The support for custom processing functionalities to be incorportaed based on need basis.


Prerequisites:
Tools :IronPython 2.7.5 (https://ironpython.codeplex.com/)
Supported Autosar versions :4.0.1 to 4.3.0  
  


Configuration:
The configurations are provided through the config.xml file. The ARXML package paths has to configured accordingly for the tool to find the 
respective elements.


Command file format:
It's a sequence of commands to the Post processing tool. To support  multiple post processing functionalities, the file format is organized
as series of command and data sets. The command string will be enclosed in "[ ]" which defines the type of processing and the format of the 
command data.The data is enclosed in "{}" curl brackets.The data are the elements in the ARXML file for example S/R port name, Implementation 
data type, Runnable names etc. The data should be organized in key value pair.Before processing the data the tool will search for the data in 
the given ARXML file for the validity and then operates on it.Till it encounters a new command string, the tool will process the data based on 
previous command.

Command and data sequence set

[command]
{ --> Data start token
key1 = value  --> Key, Value pair data
key2 = value  --> Key, Value pair data
key3 = value  --> Key, Value pair data
} --> Data end token
 


Valid format Examples:

[ArrayofUserDefinedTypes]       --> Command

Invalid Valid format Examples:

Invalid format#1:
Combining Data start/end token and data key value pair
[ArrayofUserDefinedTypes]       --> Command
{rSR_DkMsgACC = (SDkMsgACC_t,4) pSR_DkMsgACC = (SDkMsgACC_t,4)} --> Data 	

Invalid format#2:
Missing data start/end token
[ArrayofUserDefinedTypes]       --> Command

rSR_DkMsgACC = (SDkMsgACC_t,4)  --> Data key value pair

List of supported commands:
																						
Commands :

   Description:
   Generates array of user defined record data types.

   Command string : ArrayofUserDefinedTypes 
      
   Data format:	port_name = (data_type,size)

   Command Id : 1 
  																																						 
   The command Id can be used by clients to identify the type of the command.
   1)The tool creates the array implementation data type of type "data_type" with size as "size"  																																						 
   2)It creates a new S/R interface with data element as array type created above.
   3)It creates a constant specifiction for the created array of user defined data type.
   4)Finally, the tool updates the data element reference for the "port_name" with the newly created array type and updates the init value 
     referecne with newly created constant specification
